# MBP Intel Implementation Plan

> For agentic workers: use Superpowers subagent-driven-development with Fossil
> equivalents for version-control operations, as explicitly requested by user.

**Goal:** Build and verify a striking purple Alpine edge Sway workstation that
can be restored from its Fossil repository and archived artifacts.

**Architecture:** Independent desktop, packaging/rebuild, and security units.
The controller integrates and tests the complete live system. Keep actionable
runtime evidence and unresolved requirements in `alpine/PROGRESS.md`.

**Tech stack:** Alpine APK/OpenRC, Fossil, POSIX sh/Python, Sway/Waybar, OpenSnitch.

**Spec:** `docs/superpowers/specs/2026-09-07-mbp-intel-design.md`.

## Global constraints

- Alpine edge, x86_64, MacBookPro11,5; Fossil branch `alpine-oldbook`.
- Preserve existing AGENTS.md and historical source dotfiles.
- No npm, no credentials committed, no blind network teardown.
- Pin inputs and retain APK artifacts; syntax checks do not prove runtime.

## Task 1: Desktop

- [ ] Build HOME overlay under `alpine/desktop/` and document dependencies.
- [ ] Use `~/.local/share/mbp-intel/wallpaper.png` as background asset contract.
- [ ] Validate with `sway --validate --config alpine/desktop/.config/sway/config`.
- [ ] Deploy, reload, inspect actual rendered display and helper behavior.

## Task 2: Rebuild and deployment

- [ ] Implement `alpine/bin/deploy-home`, supporting `--target HOME` and backups.
- [ ] Test deployment twice into a temporary HOME, including conflict recovery.
- [ ] Implement package archive/hash/restore commands and Fossil backup.
- [ ] Verify all APKs and restore exact closure into an isolated test root.
- [ ] Document installation, rollback, update and offline rebuild commands.

## Task 3: Privacy and security

- [ ] Build pinned OpenSnitch source into local APKs with OpenRC integration.
- [ ] Create root-owned radio controls and trusted-profile configuration.
- [ ] Document and test packet filtering, process rules and daemon failure.
- [ ] Establish recovery, then activate the selected radio/boot policy.
- [ ] Record reboot and physical RF verification limits explicitly.

## Task 4: Integration review

- [ ] Independently review changes for secret leakage, unsafe deployment,
      ineffective firewall/radio claims, broken startup and rebuild omissions.
- [ ] Commit verified units with Fossil and tag only verified full releases.
- [ ] Audit each spec requirement against runtime evidence before completion.
