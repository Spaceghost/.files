# On-screen feedback pill and screenshot shutter — 2026-09-08

## What

`oldbook-osd` is one GTK 3 + gtk-layer-shell daemon per compositor session
that owns two surfaces on the overlay layer:

- **The pill.** A 300×66 logical-pixel capsule at the bottom centre of the
  focused output: Nerd Font glyph, label, amber bar on a charcoal trough and
  the percentage, all from `overlay_theme.read_palette` so generated themes
  recolor it. Kinds: `volume`, `mute`, `mic`, `mic-mute`, `brightness`,
  `keyboard`. It holds 1.1 s and fades over 260 ms.
- **The wash.** A full-output cream flash (`oldbook-flash` namespace) at 0.85
  opacity fading to zero over 120 ms, requested by `oldbook-screenshot` only
  after grim has written the file, so the flash never appears in the capture.

The daemon listens on `$XDG_RUNTIME_DIR/oldbook/osd.sock` (datagrams, JSON,
512 bytes max, validated by `osd.parse_message`). `oldbook-osd show` and
`oldbook-osd flash` are socket-only clients: without a daemon they exit 0 and
create nothing, so a key press can never block on GTK. `oldbook-osd preview
--output pill.png` renders the pill through the same drawing code with no
display, for review and evidence.

`oldbook-audio` reads the new level and mute state after each WirePlumber (or
PulseAudio) change and reports it. `oldbook-brightness` reports its percentage
instead of posting a progress notification; the permission and missing-device
notifications remain. `oldbook-screenshot` flashes, plays
`camera-shutter.oga` from `sound-theme-freedesktop` through `pw-play`, then
opens Satty with the Gruvbox profile in `~/.config/satty/config.toml` (Swappy
remains the fallback); `sway/local.d/screenshot.conf` floats the Satty window.

## Why these choices

- **Overlay layer, exclusive zone 0, keyboard mode none, empty input region.**
  The pill reserves nothing, takes no focus and passes pointer input through,
  yet an exclusive zone of zero still keeps it clear of the bar and the
  workspace caption. Not setting a monitor lets the compositor place each map
  on the focused output.
- **Frame clock only.** The hold is one single-shot timeout; the fade runs
  from a tick callback sampling `GdkFrameClock.get_frame_time`, and the
  surface is unmapped when the alpha reaches zero, so nothing redraws while
  hidden (MOTION). A linear fade settles at exactly zero; a new reading during
  a fade snaps back to full opacity. `gtk-enable-animations = false` skips both
  the fade and the flash.
- **SwayFX effects by namespace.** `layer_effects "oldbook-osd"` adds blur,
  xray, shadow and a 14 px corner radius that matches the drawn capsule; the
  flash keeps its own namespace so it stays a plain wash.
- **Session ownership.** `oldbook-session` starts the daemon through
  `start_service`; the daemon also holds `oldbook/osd.lock` and refuses a
  `SWAYSOCK` outside its runtime directory, so the session test's fake HOME
  never launches a real daemon.

## Verification

- `python3 -m unittest alpine.tests.test_osd alpine.tests.test_screenshot_shutter
  alpine.tests.test_session alpine.tests.test_feature_contracts`: 30 tests,
  covering message validation, glyph/label selection, hold/fade/flash timing,
  the quiet client, the runtime-directory guard, headless preview rendering,
  and the audio, brightness and screenshot helpers against stubbed tools.
- `python3 alpine/tests/verify_osd.py --output <new dir>` runs the real daemon
  in a private headless SwayFX session (pixman renderer): the pill maps on the
  overlay layer at 300×66, the focused workspace rectangle is identical while
  it is shown, the capture is brighter mid-fade than at rest and the surface
  is unmapped afterwards, a second reading during the fade reuses the surface,
  the flash raises the mean luma of the whole output and is gone 0.5 s later,
  Satty opens floating as `com.gabm.Satty` with the repository config accepted.
  Evidence: `alpine/verification/osd/`.
- ShellCheck passes for the four shell helpers.
- Live session: the daemon starts from a Sway reload and the client reaches its
  socket. The laptop display was powered off and locked during this work, so
  the physical look of the blur, shadow and fade on eDP-1 is pending a display
  wake; the headless run cannot show SwayFX blur under pixman.

## Rollback

Remove the `oldbook-osd` block from `oldbook-session`, the two
`layer_effects "oldbook-osd"` blocks, and restore the previous
`oldbook-audio`, `oldbook-brightness` and `oldbook-screenshot` from Fossil.
Uninstalling `satty` alone returns annotation to Swappy; uninstalling
`sound-theme-freedesktop` silences the shutter without affecting captures.
