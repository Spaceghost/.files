# Power deck: wlogout over the blurred desktop

`Super+Shift+E` and a left click on the battery module open `oldbook-power`,
which runs wlogout 1.2.2 as a layer-shell surface spanning the internal display
and falls back to the command deck's fuzzel session menu when wlogout is not
installed. A second press while the deck is open closes it instead of stacking
another copy. The five tiles are lock, suspend, log out, reboot and shut down
(keys `l`, `u`, `e`, `r`, `s`; Escape closes).

## Actions

Every tile calls `oldbook-power <action>`, so the layout needs no shell
features of its own and the actions stay reviewable in one script:

- `lock` runs `oldbook-lock`, preserving its readiness and identity contract.
- `suspend` suspends only after `oldbook-lock` succeeds, exactly like the
  command deck's suspend entry.
- `logout`, `reboot` and `shutdown` ask first on a swaynag bar before
  `swaymsg exit`, `loginctl reboot` or `loginctl poweroff`. The SESSION pin
  requires logout confirmation; reboot and shutdown are more destructive than
  logout, so they use the same step. `~/.config/swaynag/config` gives those
  bars Gruvbox colours and Inter.

## Appearance

The window tints the desktop; SwayFX blurs behind wlogout's `logout_dialog`
layer namespace through `layer_effects` in both effects.conf copies, so the
painting shows through frosted glass. Tiles are charcoal with 22-pixel corners,
cream Inter labels and a glyph on top; hover, keyboard focus and press turn a
tile amber with a near-black glyph. GTK cannot load SVG here (no pixbuf
loader), and wlogout labels take no markup, so the Nerd Font glyphs (lock,
sleep, logout, restart, power) are rasterised once by
`alpine/bin/build-wlogout-icons` into `alpine/desktop/.config/wlogout/icons/`
in both cream and near-black variants; the stylesheet references them relative
to itself, which the deployed symlink tree preserves.

Geometry for the 1440x900 logical display: five tiles per row, 22-pixel column
spacing, 96-pixel side margins and 300-pixel top/bottom margins.

## Verification

`alpine/themes/preview --power-deck` renders the deck in a private headless
SwayFX session with the production layout and stylesheet; the screenshot and
hashes are in `alpine/verification/power-deck/`. The live session was locked
with its display powered off during this work, so the binding, the battery
click and a physical tile press remain to be observed on the real display.
`sway --validate` passed for both the stock and SwayFX entry configurations.

## Recovery

Remove wlogout or delete `~/.config/wlogout/` to fall back to the fuzzel
session menu automatically; `oldbook-control power` is unchanged. The previous
`Super+Shift+E` behaviour was a direct swaynag logout prompt, now reachable as
the deck's Log out tile.
