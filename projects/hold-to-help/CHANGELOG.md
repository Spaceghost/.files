# Changes

## 0.1.0

Initial standalone release candidate extracted from Oldbook's contextual
shortcut guide. Retains hold/release cancellation, pointer scrolling, Sway and
tmux context, and user application profiles. Adds Qt desktop theming, X11
integration, a configurable physical trigger, CMake installation, and an Alpine
package. Source and package artifacts are prepared locally; no upstream LXQt
inclusion or public distribution is implied.
