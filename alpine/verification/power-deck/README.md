# Power deck render

`power-deck.png` was rendered on 2026-09-08 by `alpine/themes/preview
--power-deck` in a private headless SwayFX session: wlogout 1.2.2 with the
production layout and stylesheet, launched with the same geometry as
`oldbook-power` (five tiles, 96-pixel side and 300-pixel top/bottom margins)
over the pinned Yosemite painting, with the desktop frosted by the
`logout_dialog` layer effect. `evidence.json` records the compositor, artwork
and screenshot hashes.

Not covered here: a physical press of `Super+Shift+E` or the battery module,
tile actions (each runs `oldbook-power <action>` and was exercised only by
shell review and ShellCheck), and the swaynag confirmation bars. The live
session was locked with its display off during this work.
