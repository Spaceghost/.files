# Waybar music controls recovery, 2026-11-23

Waybar's previous, play/pause and next controls and track metadata were
missing while the audio visualizer remained visible. The active Gruvbox
configuration still listed all three MPRIS modules. From the same session bus,
`playerctl --player=io.github.Pithos status` reported `Playing` and Pithos
returned the current title and artist.

Sending `SIGUSR2` to the session's Waybar process restored the controls and
metadata. The same Waybar process remained active and Pithos kept playing.
The [cropped capture](2026-11-23-recovered.png) shows the restored controls and
metadata. The reload required no configuration or package changes. The cause
of the initial disappearance remains unconfirmed.
