# Theme workshop

Evidence for `THEME-WORKSHOP`: a theme typed into the command deck is designed
as text and applied at once, with no painting in the way.

- `menu.json`: the rows the deck's theme menu offers, built by the real
  `oldbook-control theme()` against the shipped catalogue with the menu
  replaced by a recorder and the launcher disarmed. The three workshop rows
  follow the catalogue: describe it here, surprise me, and the artwork gallery.
- `design-dry-run.json`: one real design through the Alienware rung alone
  (Ollama 0.33.3, `qwen3.5:27b-text`, 544 seconds) in a scratch copy of the
  checkout, for "a monastery library after dark, ink and candlelight". The
  descriptor came back as *Scriptorium Shadows*; the pointer set and folder
  icons were chosen here, not by the model; every profile file, the pointer
  shapes and the power-deck tiles rendered from it, with sixteen distinct
  terminal colours. Nothing was applied and nothing was painted.

What this does not show: the deck's prompt under a hand, a `create` on the
live desktop, the background boot publish, or any painting. An agent does not
exercise those on the live session; they are first sightings for Jack.
